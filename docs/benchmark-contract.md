# Benchmark Contract

## Rating scale

| Rating | Score |
|---|---:|
| Excellent | 4 |
| Strong | 3 |
| Acceptable | 2 |
| Weak | 1 |
| Fail | 0 |

A hard gate failure forces `Fail`. Policy blocks and infrastructure failures are excluded from agent
scores and make required coverage inconclusive. Run metadata reports attempted, model-completed, judged,
blocked, and infrastructure-failed cases separately.
